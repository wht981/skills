# 知识地图格式

仅当用户明确要求保存或维护地图，并确认目标工作区时，创建 `knowledge-map-<topic-slug>/`。主题别名使用全小写和短横线，例如 `knowledge-map-typescript/`。运行时生成的地图文件必须全部位于这个目录中。

```text
knowledge-map-<topic-slug>/
├── README.md               # 地图入口和根层
├── nodes/                  # 仅为已展开节点创建
│   └── <node-id>.md
└── sources.md              # 仅在需要来源索引时创建
```

这不是个人学习工作区。不要在其中保存课程、练习、学习记录、掌握状态或项目代码。

## README.md

`README.md` 只保存地图范围和根节点的直接子层。每个节点使用稳定 ID；未展开的节点不需要对应文件。

```md
# <主题> 知识地图

## 范围

- 包含：<本地图覆盖的子领域>
- 不包含：<明确排除的相邻领域>

## 根层

- `TS-01 类型系统基础`：<它在整个领域中的作用>
- `TS-02 语法与类型表达`：<它在整个领域中的作用>
- `TS-03 泛型与类型抽象`：<它在整个领域中的作用>

## 关系

- `TS-01` --前置依赖--> `TS-03`
- `TS-02` --推荐关联--> `TS-03`
```

## 节点文件

只有节点被用户选择展开，或用户要求连续展开某条分支时，才创建 `nodes/<node-id>.md`。节点文件只展示一个层级，保留回到父级和根层的链接。

```md
# TS-02 语法与类型表达

父级：[根层](../README.md)

## 直接子节点

- `TS-02-01 基础类型与字面量类型`：<简短作用>
- `TS-02-02 对象类型与属性修饰符`：<简短作用>
- `TS-02-03 联合、交叉与类型别名`：<简短作用>

## 关系

- `TS-02-03` --前置依赖--> `TS-03`
- `TS-02-03` --应用分支--> `React props 类型`
```

当用户要求“展开到最底层”时，沿其指定分支连续创建后代节点文件，直到每个叶节点都是当前范围内的最小结构单元。不要为未选择的兄弟分支预先创建文件。

## sources.md

仅在地图的版本、生态或争议性判断需要依据时创建。记录来源链接、来源性质和它支撑的地图判断，不复制外部全文，也不把它写成阅读清单。

```md
# <主题> 地图来源

- [官方文档标题](https://example.com): 官方文档。用于确认 <具体节点或关系>。
```
